This is the second release candidate for rapidgzip-unpythoned 0.16.0, with cosmetic improvements to the release process.

It packages the unchanged upstream rapidgzip 0.16.0 CLI as a standalone Linux x86-64 executable, compatible with modern distributions. The binary has been tested on Debian 13 and Ubuntu 24.04 LTS.

The archive also includes the README, upstream and third-party license texts, generated third-party notices, and the binary's OSS attribution output.
