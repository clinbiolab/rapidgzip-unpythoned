**rapidgzip-unpythoned 0.16.0** builds rapidgzip 0.16.0 directly from its upstream native C++ implementation as a standalone Linux x86-64 executable, with no Python environment required.

The binary is intended for modern x86-64 Linux systems and has been tested on Debian 13 and Ubuntu 24.04 LTS.  

To install it, download the release archive together with its `.sha256` file, verify the checksum, and extract it:

```sh
sha256sum -c rapidgzip-unpythoned-0.16.0-linux-x86_64.tar.gz.sha256
tar -zxf rapidgzip-unpythoned-0.16.0-linux-x86_64.tar.gz
./rapidgzip-unpythoned-0.16.0-linux-x86_64/rapidgzip --version
```

You can then move `rapidgzip` somewhere on your `PATH` if desired.

The archive also includes the README, upstream and third-party license texts, generated third-party notices, and the binary's OSS attribution output.
